1090ES Web Receiver

Aircraft map

Reads decoded 1090ES/ADS-B frames from an LR2021 EVK over Web Serial or WebUSB, decodes DF17 (identification, CPR position, velocity) entirely client-side, and plots live traffic - a dump1090-style receiver with no backend.

This browser exposes neither the Web Serial API (navigator.serial) nor WebUSB (navigator.usb). Use a recent Chrome, Edge, or Opera build on desktop or Android.
